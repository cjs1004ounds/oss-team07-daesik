# 광운대 주변 음식점 추천 지도

광운대 학생이 직접 남긴 기록을 지도에서 보고, 거리와 가격으로 걸러 학교 주변 음식점을 찾는 웹 앱입니다.
2026년 2학기 오픈소스소프트웨어및실습 team07 프로젝트입니다.

> 기획은 진행 중입니다. 아래 내용은 제안 이슈([kw-hdi-lab/oss2026-project#7](https://github.com/kw-hdi-lab/oss2026-project/issues/7))에 받은 피드백을 반영한 초안이며, 팀 회의에서 바뀔 수 있습니다.

## 왜 만드나

- 신입생은 아는 선배가 없으면 학교 근처 어디가 괜찮은지 물어볼 곳이 없습니다.
- 복학생은 휴학한 사이 가게가 생기고 없어져서 예전에 알던 정보가 맞지 않습니다.
- 에브리타임 글은 금방 묻히고, 지도 앱 리뷰는 학생 기준(도보 거리, 1인 가격)으로 거를 수 없습니다.

## 기록이 쌓이는 방법

이 서비스는 기록이 쌓이지 않으면 쓸모가 없습니다. 읽는 사람은 신입생과 복학생이지만 쓰는 사람은 학교를 오래 다닌 재학생이므로, 재학생이 따로 시간을 내지 않아도 기록이 남도록 두 가지 길을 둡니다.

### 1. 밥 먹을 곳을 고르다 보면 기록이 남는다

친구들과 "오늘 뭐 먹지"를 정하는 일은 원래 하던 행동입니다. 이 과정을 앱에서 하게 만들고, 그 결과를 기록으로 씁니다.

1. 한 명이 방을 만들고 링크를 단톡방에 올립니다.
2. 각자 링크로 들어와 후보 가게에 투표합니다.
3. 가장 많은 표를 받은 가게가 정해지면 방문 기록이 하나 남습니다.
4. 다녀온 뒤 같은 링크에서 "또 갈래요" 또는 "글쎄요"를 한 번 누릅니다.

글을 한 줄도 쓰지 않아도 "몇 명이 갔고, 그중 몇 명이 또 가겠다고 했는지"가 쌓입니다.

### 2. 한 줄만 쓰면 나머지는 채워진다

직접 추천을 남기고 싶은 사람은 가게를 고르고 한 줄만 씁니다.

```
제육 7천원인데 양 많음 혼밥하기 좋음
```

서버가 이 문장을 LLM에 보내 음식 종류, 1인 가격, 태그(양 많음, 혼밥)를 뽑아 입력 칸에 미리 채웁니다. 작성자는 확인하고 저장만 누르면 됩니다. LLM 호출이 실패하면 칸을 직접 채워 저장할 수 있습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 지도에서 찾기 | 학교 주변 가게를 지도에 표시하고, 도보 시간과 1인 가격, 음식 종류로 거릅니다 |
| 같이 정하기 | 방을 만들어 후보에 투표하고, 정해진 가게를 방문 기록으로 남깁니다 |
| 한 줄 추천 | 한 줄을 쓰면 LLM이 입력 칸을 채워 줍니다 |
| 가게 상세 | 방문 횟수, 또 가겠다는 비율, 한 줄 추천 목록을 보여 줍니다 |

가장 먼저 완성할 기능은 "가게를 골라 한 줄 추천을 남기고, 지도에서 그 가게를 눌러 확인하기"입니다.

## 계산 규칙

화면 코드와 분리된 함수로 두고 테스트합니다.

- 학교 기준점과 가게 사이의 직선거리를 도보 속도(분당 약 67m)로 나눠 도보 시간을 구하고, 15분이 넘는 가게는 제외
- 투표 집계: 표가 가장 많은 가게를 고르고, 동점이면 도보 시간이 짧은 가게를 선택
- 최근 7일 안에 같은 방에서 간 가게는 후보에서 제외
- 또 가겠다는 비율 = "또 갈래요" 수 / 전체 응답 수, 응답이 3개 미만이면 "기록 부족"으로 표시
- 입력값 검사: 가격은 양의 정수, 한 줄 추천은 5~100자
- 같은 익명 ID로 같은 가게에는 하루에 한 번만 등록
- 같은 검색어로 가게를 검색하면 10분 동안은 저장된 결과를 사용

## 기술

- 프론트엔드: HTML, CSS, JavaScript (프레임워크 없음)
- 백엔드: Node.js, Express
- 저장: JSON 파일 (저장 모듈로 감싸서 나중에 바꿀 수 있게 함)
- 외부 API: 카카오 로컬 API(가게 검색), 카카오맵 JavaScript SDK(지도), LLM API
- 로그인은 없습니다. 브라우저마다 발급한 익명 ID만 쓰고, 이름이나 학번 같은 개인정보는 받지 않습니다.

API 키는 저장소에 올리지 않고 환경 변수로 관리합니다.
